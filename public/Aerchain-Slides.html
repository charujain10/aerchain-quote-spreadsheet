Kill the Quote Spreadsheet

Aerchain Product Take-home

Charu Jain

Corrugated packaging · RFx CORR-2026-118 · 30 lines · 5 vendors

The problem

  • Buyers lose 3–4 days retyping quotes from Excel, PDF, Word, email, and photos
  • VP asks: “Split award — cheapest per line — only vendors who passed quality” → another day in Excel
  • We built the loop that ends the quote spreadsheet

One flow, end to end

  1. AI co-pilot drafts RFx (scope, 30 lines, questionnaire)
  2. Send to vendors (SMTP stubbed; bundled replies for demo)
  3. Ingest any file shape → extract & normalize to INR/box
  4. Compare 30×5 grid + confidence, flags, attachments
  5. Analyst — NL questions → tables, charts, CSV, award math

Response: flags, confidence, provenance — not silent wrong numbers

Trust (₹4Cr narrative)

  • Prices link to source snippets from attachments
  • Quality gate before split-award scenarios
  • Analyst answers computed from extracted data — not hardcoded
  • CSV exports for audit (comparison, questionnaire, split award)

Architecture

Vendor files → Parsers (SheetJS, pdf-parse, Mammoth, email/SVG rules) → Normalize (USD→INR, UOM, missing lines) → 30×5 grid + questionnaire → NL analyst (split award, totals, review queue) → CSV export

LLM v2: gpt-4o-mini + vision on low confidence only — not on public URL (determinism, cost, key safety)

Live demo (6 min)

  1. Co-pilot → Generate RFx
  2. Mark sent
  3. Load all 5 demo vendor files
  4. Compare + questionnaire
  5. Analyst: quality pass → split award with filter → export CSV

Left out (48h scope)

  • Real SMTP / vendor portal
  • ERP & legal award workflow
  • Production camera OCR
  • Multi-tenant auth

Product insight

The hard problem isn’t OCR — it’s matching vendor language to canonical RFx lines.

Next: buyer-in-the-loop matching → learn corrections → agentic re-quote on gaps
